## Screens

### 1. Splash Screen
- Shows when you first open the app
- Displays a campfire icon 🔥 and the title **Campsite Commander**
- Automatically transitions to the main screen after **3 seconds**
- Uses a Kotlin **Coroutine** for the timed delay (no freezing the UI)

### 2. Main Screen
- Shows the **total number of items packed** (calculated with a FOR loop through the data arrays)
- **Add Gear** button → Opens a dialog where you can type in a new item name, category, and comment
- **View Detailed Checklist** button → Takes you to the full checklist screen
- Dark nature-themed design with forest green accents

### 3. Detail Checklist Screen
- Displays every gear item as a separate card
- Each card shows: **item number**, **name**, **category**, and **extra details**
- Built dynamically using a **FOR loop** through the parallel arrays
- **Back to Base** button takes you back to the main screen
